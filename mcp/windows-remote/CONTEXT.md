# windows-remote 领域术语表

本文件是 glossary,只记录领域词汇的精确含义,不含实现细节。

## 命令与附件

- **命令（Command）**：请求在远程 PC 上执行的一条命令文本。
- **附件（Attachment）**：命令执行前必须先送达远程工作区并通过完整性校验的本地文件；在命令中以文件名引用，而非路径。
- **远程工作区（Workspace）**：远程 PC 上的固定目录；附件在此就位，命令以此为其工作目录。
- **缓存清单（Manifest）**：与附件关联的内容指纹记录；指纹一致时附件视为已就位、跳过传输，内容变化即自动失效。
- **两阶段执行（Two-Phase Execution）**：全部附件就位且校验通过之后，命令才允许执行；任一附件失败则命令不执行。
- **残留进程（Orphan）**：会话超时或断开后仍在远程运行的命令进程；按命令特征识别并清理。

## 工具分层

- **通用命令工具（Generic Command Tool）**：以「命令 + 可选附件」表达一切远程命令的统一入口；不承载任何协议特有语义。
- **专用工具（Specialized Tool）**：面向单一协议（adb / fastboot / uart 等）的工具，承载该协议特有的语义修正（如防挂起、PTY 分配、串口文件通道）；与通用命令工具共享同一执行层。

## 校验语义

- **完整性校验（Integrity Check）**：附件内容指纹的双端比对；不一致即失败，失败即中止，不自动重传、不自动清理现场。
