# Step 7: 自主学习与收录

任务执行结束后，根据过程中发现的新模式/新类型，执行收录流程。

## 1. 新类型/新模式收录

如果本次任务中遇到了新的 **功耗根因类 / 睡眠档位模式**（不在已有的知识库中），用 `AskUserQuestion` 提示用户确认是否收录：

```
question: "本次发现了一个新的功耗根因类/模式，是否收录到 skill？"
header: "收录"
options:
  - label: "收录并更新知识库"
    description: "将新模式同时加入 references/ 和 data/ 的知识库"
  - label: "仅收录到 data/（自学习库）"
    description: "只更新自学习库，不修改参考文档"
  - label: "这次先不收录"
    description: "跳过，后续手动补充"
```

收录时自动提取的关键字段：
- **特征标识**：如 aosd=0 && cxsd>0、gpioX out high、spm_lvl=3  
- **类型名**：根因类短名（CLASS_*）  
- **处理要点**：验证有效的步骤与 ΔmA  

## 2. 新场景/新输入模式收录

如果用户提供了新的 **测流场景/平台别名**（不在预设选项中）：

1. 归纳为短标签（≤12 字）和一句描述（≤50 字）  
2. AskUserQuestion 确认是否写入 Step 0 选项  
3. 确认后更新 `step-00-collect.md`  

## 3. 反馈闭环（被动触发）

**本轮不主动询问反馈。**

当用户后续说「修好了 / 电流达标了 / 根因确认了 / aosd 有 Count 了」等，进入 `workflows/feedback-loop.md`。

---

**所有步骤完成。如果用户有新的任务，从 Step 0 重新开始。**
