# 案例 96299:高温软重启后不开机

- 项目/平台:MT5825(Khaje/Bengal 家族,kernel 5.15.170)
- 条件:高温 + 4V/3A 供电,循环软重启,~5/2000 概率重启后不开机,手动可恢复
- 证据:串口 log(失败轮现场 3 次:行 279533/279700/284030)

## 根因

失败轮真实现场在 **UEFI 阶段——电源键状态检测误判**:打印
`Invalid pwrkey press. Shutting down!` 后直接关机,须手动 KPDPWR 开机才能恢复。
置信 0.85(3 次失败轮直接日志证据,均位于 UFS INQUIRY 成功后、Booting Linux 前)。

## 定案关键信号

1. 失败轮 UEFI 段的 pwrkey 误判打印(唯一硬指纹)
2. 失败点位置:存储枚举成功后、内核启动前(排除存储链)
3. PS_HOLD 干净关机特征 + 需手动开机的恢复行为

## 被证伪的假说

| 假说 | 证伪证据 |
|------|----------|
| SBL1-UFS 假说(初判) | 失败点在 UFS INQUIRY 成功之后,推翻 |
| eMMC/SDCC 路线 | 实机 boot device 是 UFS(mmc0=Wi-Fi SDIO,mmc1=SD);票面标注 eMMC 有误 |
| 文件系统损坏 | fsck.f2fs 修复后挂载正常 |

## 分诊校准教训

triage 判 storage(症状指纹误导),实际 root=power(UEFI 电源键误判),
triage_correct=false——「重启后不开机」必须先分流:UEFI 段失败看电源键/按键
状态,存储段失败才走存储链;**票面硬件标注(如 eMMC)要与实机识别交叉验证**。
