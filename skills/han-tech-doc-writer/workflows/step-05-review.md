# Step 5: 质量审核

输出前进行自查，确保文档质量。逐项检查，发现问题立即修复。

## 5.1 完整性检查

- [ ] 所有章节都已填写内容，无空白段落
- [ ] 没有 "TODO"、"待补充"、"TBD" 标记（有意标注的除外）
- [ ] 每个 D2 图表都有对应的文字说明
- [ ] 每个信息图都有对应的说明文字
- [ ] Step 2 计划的所有 D2 图表都已生成并嵌入
- [ ] Step 2 计划的所有信息图都已生成并嵌入（或标注缺失）
- [ ] 文档头部和尾部信息完整

## 5.2 准确性检查

- [ ] 技术术语拼写正确（英文大小写、下划线、括号匹配）
- [ ] API/函数名与源文档一致
- [ ] D2 图表中的节点名、连接关系与实际一致
- [ ] 信息图中的概念与正文一致
- [ ] 数据/数字与源文档一致
- [ ] 没有凭空编造的内容

## 5.3 格式检查

- [ ] 标题层级正确（h1 → h2 → h3，不跳级）
- [ ] 代码块标注了正确的语言类型（```c、```python、```bash 等）
- [ ] 图片路径正确（`_diagrams/<name>.png`）
- [ ] 表格对齐整齐，表头加粗
- [ ] 列表项语法一致

## 5.4 D2 图表质量检查

- [ ] 每个图都有编号和标题（图 N: 标题）
- [ ] 图标题使用斜体：`*图 N: 标题*`
- [ ] 正文中有图引用（"如图 N 所示"）
- [ ] 图片文件存在且非空（`ls -lh _diagrams/` 验证）
- [ ] 中文标签无乱码

## 5.5 信息图质量检查

- [ ] 信息图文件存在且非空
- [ ] 信息图在文档中显示正常（路径正确）
- [ ] 信息图位于醒目位置（文档开篇/章节开篇）
- [ ] 信息图内容与 D2 图表互补（不重复）
- [ ] 信息图中的中文清晰可读（无乱码、无截断）
- [ ] 信息图下方有引导性说明文字
- [ ] 信息图不使用图号，与 D2 图表编号体系独立

## 5.6 不通过处理

如果某项不通过：
- 格式/文本问题 → 直接修复
- D2 图片问题 → 回到 Step 3 重新编译
- 信息图问题 → 回到 Step 3.5 重新生成，或标注缺失后继续
- 内容准确性问题 → 回到 Step 4 修正
- 结构/完整性问题 → 回到 Step 2 调整大纲

**全部通过后，读取 `workflows/step-06-output.md` 继续。**
